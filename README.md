Ember Run — a volcano-rescue flight game at dawn: fly three sorties over a smoking archipelago, thread the golden rings, watch fuel, damage and crosswind, and land on the named airstrips (Kora, Ember, Meridian Field) to refuel and patch up before the final touchdown.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Fly with arrow keys or WASD, W/S for throttle, mouse to steer, P to pause, M to mute.
